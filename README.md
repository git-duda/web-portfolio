# Eduarda Saraiva — Portfólio

Portfólio de Economia, Análise e Dados, com apresentação pessoal, exemplos interativos e formulário de contato. Interface disponível em português e inglês.

## Desenvolvimento

Requisitos: Node.js 22 e npm.

```bash
npm ci
npm run dev
```

## Verificação e build

```bash
npm run typecheck
npm run build
```

A publicação utiliza a pasta `dist/`. A configuração para a Vercel está em `vercel.json`.

## Contato e exemplos

O formulário utiliza FormSubmit para encaminhar mensagens a `eduardakrr@gmail.com`. O recebimento requer ativação pelo destinatário. Nenhuma chave de API é necessária.

Os gráficos e calculadoras do portfólio são demonstrações com dados locais. Os links dos projetos completos estão nas respectivas seções.
